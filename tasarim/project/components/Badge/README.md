# Badge

Aile rozeti: kazanılmışsa tarihi, kazanılmamışsa nasıl kazanılacağı ve ilerlemesi.

- `ak-badge`: solda `<i>` içinde rozet emojisi (`kandil` halkalı daire), sağda `<b>` ad ve `<small>` açıklama.
- `is-locked`: gri simge, açıklama “nasıl kazanılır” cümlesidir ve altında `ak-badge__bar` ilerleme çubuğu (`kandil`) bulunur.
- Rozetler aile içindir, kişilere verilmez; rekabet değil ortak hedef dili kullanılır.
