# KissaCard

Kıssa Kartları albümündeki toplanabilir kart; mihrap kemeri biçiminde.

- `ak-kcard` + `--c`: kategori rengi. Kıssa kartları `nar`, ses kartları `kandil`, hayvan kartları `zumrut`.
- İçerik: `<i>` içinde emoji, `<b>` içinde kartın adı. Dokununca kıssası okunur.
- Durumlar: `is-new` (köşede “Yeni” etiketi; albüm bir kez açılınca kalkar), `is-missing` (henüz bulunmamış: yıldız desenli gri, “?” ve kategori adı; adı gizli kalır).
- Albümde üç sütunlu ızgarada `aspect-ratio: 3 / 4` ile kullanılır.
