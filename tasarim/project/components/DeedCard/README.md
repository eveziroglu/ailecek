# DeedCard

Gizli iyilik görevini gösteren yıldızlı gece kartı; markanın en özel yüzeyi.

- `ak-deed`: `gece` zemin, `yildiz` yıldızlar, üstte mihrap kemeri. İçerik sırası: `ak-deed__eyebrow`, `ak-deed__to` (gizli dostun avatarı), `ak-deed__name`, `ak-deed__text` (görev), `ak-deed__seal` (mühür, kart mühürlenince görünür), `ak-deed__quote`.
- Kart yalnızca görevin sahibi bakarken açılır; hiçbir zaman sesli okunmaz.
- Üzerindeki butonlar `ak-btn--kandil` (Mühürle) veya `ak-btn--night` (Gizle).
