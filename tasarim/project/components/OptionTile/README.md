# OptionTile

Bil Bakalım sorularının cevap kutusu.

- `ak-options` kapsayıcısında `ak-option` butonları. Harfli kutu: `ak-option__key` (A, B, C) ilk sırada; harf kutusu sırayla `nar`, `cini`, `zumrut` renklenir.
- 3-5 yaş için `ak-options--pics`: üç sütun, `ak-option__pic` içinde büyük emoji ve altında tek kelime.
- Durumlar: `is-correct` ve `is-wrong`; her zaman `ak-option__mark` ile “✓ Doğru” / “✗ Yanlış” yazın. Diğer seçenekler `is-dim`. Cevaptan sonra tüm kutular `disabled`.
