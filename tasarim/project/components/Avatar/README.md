# Avatar

Bir aile üyesini hayvan simgesiyle gösteren daire.

- `ak-avatar` (56px), `ak-avatar--sm` (40px), `ak-avatar--lg` (96px). Halka rengi `--c` ile verilir; aile üyelerine sırayla `cini`, `nar`, `zumrut`, `kandil`, `lale`, `firuze` atanır.
- `ak-avatar__badge` sağ altta durum gösterir (gizli iyiliği yaptı: ✓). Rozet yalnızca kişinin kendi durumunu söyler, kime iyilik yaptığını asla.
- İçerik tek bir hayvan emojisidir; fotoğraf kullanılmaz.
