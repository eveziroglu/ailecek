# Toast

Ekranın altından kayarak gelen kısa bildirim: yeni rozet, kilitli durak uyarısı.

- `ak-toast`: gece zemini, solda `kandil` daire içinde emoji, sağda `<small>` üst etiket (`yildiz`) ve `<b>` başlık. `role="status"` verin.
- Gelir, 3 saniye kalır ve kendiliğinden kaybolur; aynı anda birden fazla bildirim art arda gösterilir.
- Eylem içermez; kullanıcıdan bir şey bekleyen içerik için kart ya da buton kullanın.
