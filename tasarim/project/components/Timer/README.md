# Timer

Halka biçimli geri sayım.

- `ak-timer` içinde `<b>` saniye. Kalan oran `--p` (0–1), renk `--c` (oyunun rengi). Son 5 saniyede `is-low`: rakam `nar` olur ve halka titrer.
- `ak-timer--sm`: Kalk-Otur gibi yan öğelerle aynı satırda.
- Süreler: Pandomim 60 sn, Ses Taklidi 45 sn, Hızlı Tur 30 sn, Kalk-Otur 5 sn.
