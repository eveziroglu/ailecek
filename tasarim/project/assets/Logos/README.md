# Logolar

`ailecek-mark.svg`: Ailecek işareti. Sekiz köşeli yıldız (iki kare) içinde bir ev, evin içinde kalp. Yıldız `cini` (#2747B5), ev beyaz, kalp `kandil` (#EAA214). Tek renkli değildir; koyu zeminde yıldızın etrafında en az 4px `surface-200` boşluk bırakın.

Yazı logosu ayrı bir dosya değildir: "Aile" kelimesini `display` ailesinde 700 ağırlıkla `cini`, "cek" ekini `kandil` renginde yazın. İşaret, yazının solunda yazı yüksekliğinin 1.2 katı boyutta durur.
