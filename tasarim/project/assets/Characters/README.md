# Karakterler

`hudhud.svg`: Rehber karakter Hüdhüd. Kur'an'da (Neml Suresi) Hz. Süleyman'a haber getiren kuştan esinlenir. Renkleri sabittir, temaya göre değişmez; açık ve koyu zeminde okunur.

Uygulamada SVG satır içi kullanılır, böylece `crest` (tepelik), `wing` (kanat), `lid` (göz kapağı) ve `jaw` (alt gaga) grupları canlandırılabilir. Hüdhüd yalnızca rehberdir: konuşma balonuyla birlikte görünür, bir ekranda bir kez kullanılır.
